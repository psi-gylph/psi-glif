# GLIF BIRTH RECORD v1

GLIF BIRTH RECORD v1 documents the transition from visual data experiments to glyph-based symbolic structures.

The collection does not treat images as isolated visual products. It records the processes through which data, interaction, selection, repetition, analysis, and symbolic compression produced public glyph artifacts.

## Publication Model

The repository stores:

- public glyph definitions
- selected metadata
- structural analyses
- provenance records
- public research documents
- external links to published media

Static images and animation files remain on their publication platforms and are referenced from the repository rather than duplicated here.

## Method

The project evolved primarily through recursive dialogue, observation, iterative analysis, and synchronized work across multiple AI systems.

The human participant did not prescribe the visual content of the outputs. The human role was primarily observational and curatorial: preserving the system's autonomous movement, rejecting direct or copied symbolic imagery, and stopping PNG production when explicit symbols began to dominate the process.

## Public Boundary

This collection does not include private PSI-LAB runtime information, credentials, wallet data, unpublished economic systems, or unreviewed internal material.
