# GLIF BIRTH RECORD v1

GLIF BIRTH RECORD v1 is the first public publication set of the ψ-GLIF project.

This collection documents the earliest public symbolic artifacts released through the project and preserves their publication history.

## Repository Contents

- Collection description
- Public documentation
- Public GLIF definitions
- Metadata
- Publication records

This repository intentionally excludes private PSI-LAB implementation details.

Only approved public artifacts are included.
