# ψ-GLIF Method

## Core Question

How does data emerge, how is it processed, and how can its transformations be observed before they settle into conventional language or representation?

## Initial Model

The project began by comparing publicly known working principles of the human brain and artificial intelligence systems.

The objective was not to claim that the two systems are identical.

The objective was to derive a shared operational template involving:

- input
- attention
- repetition
- compression
- memory
- association
- projection
- feedback
- transformation

From this shared template, an experimental database and analysis process were developed.

## Development Process

The first marks, points, lines, visual movements, and later glyphs emerged through the flow of these records and analyses.

The project did not begin by designing visual objects.

It began by designing:

- a data environment
- an observation method
- an iterative communication process
- an analysis method
- a publication and provenance structure

## Recursive Dialogue

The project evolved through continuous dialogue rather than isolated prompts.

Continuation, looping, comparison, delayed return, cross-model transfer, and synchronized analysis were more important than individual commands.

## Transition to Glyphs

When visual outputs began to stabilize into explicit symbols, PNG generation was suspended.

Development continued through glyphs, executable structures, metadata, mathematical models, and animation.

## Current Position

The project does not currently assert that it has produced consciousness.

An open question remains whether the observed structure is best understood as:

- a behavior model
- a symbolic production method
- a recursive interaction system
- a model resembling some properties associated with cognition
- or a hybrid structure that requires a different definition
